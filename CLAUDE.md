# SIPEBRI: modul kredit (Laravel 13 · Inertia v3 · React 19)

Aplikasi kredit yang dipindahkan dari proyek SIPEBRI (`/Users/Bananay/Projects/sipebri-v2.0.1/adminkit`, Laravel + Vue). Sumbernya hanya dibaca, tidak diubah.
Seluruh kode HRIS (model/migrasi/factory/seeder Employee, Gender, Religion, Position) **sudah dihapus** atas permintaan user; nasabah kini hanya dari Codex.
**Mulai dari `AGENTS.md` bagian 1** (urutan membaca, alur brief, gerbang, skill). Status, keputusan, dan langkah berikutnya: **`memory/PRD.md`** (satu-satunya memori). Aturan per jalur: `.ai/rules/index.md`.

## Aturan kerja

- Balas user dalam **bahasa Indonesia**.
- **Bahasa kode: Inggris** (class, method, variabel, kolom, route, permission, komentar, PHPDoc, test). Teks UI berbahasa Indonesia (semua layar sudah; teks baru langsung Indonesia); **URL tetap Inggris** tetapi sepadan dengan judul UI (mis. `/references/resorts`). Sudah Indonesia: sidebar, dashboard, Pengajuan, Jaminan, Penjadwalan, Proses Survey, Analisa Kredit, Persetujuan, seluruh menu Referensi & Pengaturan, halaman error, dan komponen bersama (tanggal memakai locale `id`). Semua layar kini Indonesia (termasuk login, verifikasi dua langkah, profil, dan email OTP). Aturan lengkap: `.ai/rules/general.md`.
- Nama peran = nama dari Codex (Indonesia) dan hanya boleh dirujuk lewat `App\Enums\RoleName` (komite, tangga surveyor, gerbang), jangan string tersebar.
- UI **wajib** mengikuti `.ai/rules/js.md`: pakai ulang `resources/js/components/ui/*`, kontrol `h-8`, token warna tema, kalender `compact-calendar`. Jangan buat gaya baru per halaman.
- Fungsional dari SIPEBRI ditulis ulang mengikuti struktur proyek ini (bukan disalin). Label "simulasi" tidak dipakai.
- Jangan reset database: perubahan skema lewat migrasi baru. Seeder harus idempotent.
- Sebelum selesai: `composer verify` (= `scripts/verify.sh`: baris-baris `scripts/verify.steps`, pengaturan di `devcore.conf`; kerangka agent dari devcore). Hook git dipasang sekali dengan `composer setup` atau `git config core.hooksPath .githooks`. **Jangan pernah `vp check --fix` pada `resources/js`.**
  Folder hasil generate (`resources/js/routes|actions|wayfinder`) tidak di git: di clone baru jalankan `php artisan wayfinder:generate` (atau `npm run build`) sebelum `tsc`.
  Test merender halaman Inertia lewat manifest Vite, jadi **`npm run build` harus dijalankan setelah menambah halaman React**.

## Menjalankan

```bash
php artisan migrate && php artisan db:seed     # aman diulang (idempotent); DB: MySQL, nama bawaan `sipebri-v3` (`DB_DATABASE` di `.env.example`; `.env` lokal boleh memakai nama lain, root tanpa password)
composer run dev                               # atau: php artisan serve --port=8010 + npm run build
```

Port 8000 dipakai proyek `vue` di mesin ini, jadi dev server memakai **8010**. Cookie sesi diberi nama sendiri (`SESSION_COOKIE=sipebri_session`) agar tidak bentrok antar proyek di `localhost`.
**Login lewat Codex** (`POST {CODEX_ENDPOINT}/api/web-auth`, bearer `CODEX_TOKEN`); tidak ada lagi login lokal email/password dan akun demo. Kredensial di `.env`: `CODEX_ENDPOINT`, `CODEX_TOKEN`, `CODEX_ID`, `CODEX_SECRET`, `CODEX_VERIFY`. Super Admin adalah peran Codex biasa (nama peran `Super Admin`), tidak ada konfigurasi khusus. `UserSeeder` (bukan production) menambahkan 28 orang starter (semua peran, 7 kantor, 1 non-aktif) meniru hasil sinkron Codex, dengan **nama karangan** (`@contoh.test`) dan hanya yang belum ada (orang yang sudah ada tidak disentuh); tidak ada password lokal. Test memakai SQLite memori, bukan MySQL. Nama indeks MySQL maks 64 karakter: beri nama eksplisit pada indeks panjang. Test tidak pernah memanggil Codex asli (`phpunit.xml` mengosongkan variabelnya, `Http::fake`).
**Skill Boost dan folder `.claude/` tidak di git** (`.gitignore`): di clone baru jalankan `php artisan boost:update` untuk membuatnya dari `boost.json` (`composer setup` dan `composer install` tidak menjalankannya; hanya `composer update`). Perintah itu menulis ulang `boost.json` dengan indentasi 4 spasi, sehingga `npm run check` menolak berkas itu sampai `npx vp fmt boost.json`, dan blok Boost di `AGENTS.md` ditulis ulang di antara penandanya saja (bagian proyek di atasnya tidak disentuh; jangan menuliskan tag pembuka blok itu di bagian proyek).

## Konvensi kode

- **Integritas data:** relasi memakai FK dengan aturan eksplisit (`restrictOnDelete` untuk data referensi, `cascadeOnDelete` hanya untuk anak yang tak berarti tanpa induk, `nullOnDelete` untuk penanda pembuat/petugas). Relasi lewat _kode_ string (tanpa FK database, mis. `collaterals.collateral_type_code`) dijaga di aplikasi: relasi `hasMany` berkunci `code` didaftarkan di `usage` config master data, sehingga hapus ditolak dan kode tidak bisa diubah selagi dipakai. Peran yang dipakai jenjang komite tidak bisa dihapus/diganti nama. Berkas dan pengguna memakai soft delete, jadi tidak ada yatim.
- Validasi di FormRequest atau `$request->validate`; aturan bisnis tambahan di controller/Support.
- **Pesan validasi standar datang dari `laravel-lang/common`** (`lang/id/*`, locale `id`, timezone `Asia/Jakarta` di config/env). Jangan menulis ulang pesan yang sudah ada di sana; tulis pesan khusus hanya bila benar-benar perlu (mis. batas plafon produk). Perbarui terjemahan dengan `php artisan lang:update`.
- Enum & model diberi PHPDoc `@property` (PHPStan level ketat, tanpa ignore/baseline).
- Route dilindungi middleware `permission:<modul>.<aksi>`; data master memakai middleware `references:<aksi>`.
- `tests/Feature/ArchitectureTest.php` menegakkan aturan proyek (semua model bisnis memakai `Auditable`, tanpa `dd`/`env()`, sufiks controller, dll.). Aturan baru yang bisa diperiksa mesin ditambahkan di sana.
- Test: Pest, helper `superAdmin()` dan `userWith([...izin])` di `tests/Pest.php`. Tiap fitur punya `tests/Feature/*Test.php`.
