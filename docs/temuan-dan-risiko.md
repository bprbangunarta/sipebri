# Register Temuan dan Risiko SIPEBRI

Identifikasi **EXISTING 1.0**. Register temuan/observasi dari inspeksi statis source/DDL dan keterangan pengguna. Bukan laporan insiden, bukan rencana perbaikan. Lihat [analisis skema](database/analisis-skema-mysql.md).

## 1. Batas observasi

Temuan berikut menjelaskan kondisi source/DDL dan dampak potensial, bukan hasil uji runtime. Penutupan dokumentasi tidak menyatakan temuan telah diperbaiki atau risiko diterima. Tidak ada prioritas implementasi atau penugasan dalam paket ini.

| R-18 | Platform dan aset campuran | Lockfile membutuhkan PHP >=8.2 64-bit meskipun root ^8.0.2; beberapa layout/versi JS, termasuk dua jQuery pada layout Tabler | Reproduksi/build/plugin tidak konsisten; upgrade parsial berisiko |
| R-19 | Delivery/recovery tidak terdokumentasi | Runbook dan CI aplikasi tidak ditemukan pada lokasi yang diperiksa; badge README milik Laravel upstream | Rilis sulit diulang; rollback/restore tidak terbukti |
| R-20 | Identitas/skema RSC | RSC eksternal memakai nomor rekening pada field kode lokal; `rsc_spk/rsc_data_spk` berbeda; cabang existing `simpan_spk_rsc` masih insert, padahal `rsc_data_spk.kode_rsc` unik pada ekspor | Salah penggabungan identitas; simpan ulang kunci non-null yang sama gagal duplicate-key, bukan update atau duplikat tersimpan |
| R-21 | Implementasi cabang belum selesai | `ubah_analisa` menolak administrasi kosong sebelum bypass KTA; `Admin/ResortController::simpan_resort` berhenti di `dd` | Cabang produk/maintenance tidak menghasilkan perilaku yang dimaksud kode |
| R-22 | Konflik kolom realisasi | Source lokal menulis `data_realisasi.status`; kolom tidak ada pada ekspor yang asal produksinya dikonfirmasi pengguna | Terhadap DDL ini update pertama gagal unknown-column; belum ada bukti jalur/source ini benar-benar dijalankan di produksi |
| R-23 | Insert parsial dan identitas unik | Pendaftaran mengabaikan sejumlah kolom NOT NULL tanpa default; source `strict=false`. Lookup identitas+tanggal lahir berbeda dari unique `no_identitas` | Strict mode menolak insert; non-strict memakai nilai implisit; tanggal lahir berbeda berbenturan unique |
| R-24 | Batal PK dan panjang kunci | Jalur administratif menambah `XX` ke delapan karakter dalam VARCHAR(8); jalur dropping mengganti prefix. Reset agunan di luar transaksi utama | Gagal atau suffix terpotong, relasi tidak terputus, perubahan parsial/konflik unique |
| R-25 | Constraint/index dan tipe domain | Hanya empat FK pivot, tanpa FK bisnis; indeks join tertentu tidak ada; usulan tidak unique per pengajuan+petugas dan notifikasi tidak unique per pengajuan; uang/tanggal banyak VARCHAR/INT | Orphan, multiplikasi row, beban query, salah konversi atau konflik nilai; belum terbukti terjadi |
| R-26 | Kontrak dan privilege view | Semua view SECURITY DEFINER; `v_users` multi-row tanpa filter model/active; `v_validasi_pengajuan` inner join; tanggal send\_\* dinamis; agregasi berpotensi sensitif SQL mode | Akses/hak eksekusi tidak sesuai maksud, role/tanggal/rekap ambigu atau query gagal pada mode lain |

### Bukti penyeimbang

Source juga menunjukkan penggunaan validasi Laravel, transaksi pada pendaftaran dan beberapa operasi lain, middleware role/permission, dan perlindungan CSRF web. Register ini **tidak menyatakan seluruh sistem tanpa validasi atau seluruh endpoint publik**. Kehadiran kontrol sebagian juga tidak membuktikan setiap endpoint aman.
